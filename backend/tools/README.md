FFprobe is required for upload metadata and export validation. No Python package is needed.

Install the FFmpeg companion `ffprobe` on PATH, set `FFPROBE_PATH` to its absolute path,
or place it here as `ffprobe.exe` (Windows) / `ffprobe` (Linux/macOS).

The local Windows executable was extracted from the [Gyan FFmpeg essentials build](https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip).
Executables are ignored by Git. Keep the accompanying LICENSE when redistributing the binary.
