# Cinematic font

Anton Regular is bundled under the SIL Open Font License in OFL.txt.
Source: https://github.com/google/fonts/tree/main/ofl/anton

The narrow uppercase forms were selected after inspecting the supplied reference
reel's tall, condensed display headings. Body captions use the locally installed
Arial font (DejaVu Sans on Linux). Font binaries from Windows are not redistributed.
